# Calculator App With Voice Output

A React Native calculator app with voice output support.

## Features

- Basic calculator operations
- Scientific calculator functions
- Voice output for results and interactions
- Built with React Native and TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Metro bundler:
   ```bash
   npm start
   ```
3. Run the app:
   ```bash
   npm run android
   ```
   or
   ```bash
   npm run ios
   ```

## Notes

- The project already excludes the node_modules folder from version control.
- This repository is configured to push the app source without large dependency files included.
